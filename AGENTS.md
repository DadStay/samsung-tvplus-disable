# Project working rules

Read README.md, docs/results.md, PROJECT-STATE.md and current Git state first.
Never claim a complete uninstall or Samsung-wide support. Keep exact target guards,
original receipts, bounded operations, verified cleanup and fixed report allowlist.
Do not publish private addresses, personal paths, tokens, raw device records or
proprietary binaries. Use isolated host fixtures for tests; no live writes in CI.
Inspect staged files and built ZIP before publishing. Source and documentation
changes need actual validation and an updated public checkpoint. No unsolicited
firmware patches, factory settings, shared viewer stops or persistent agents.
