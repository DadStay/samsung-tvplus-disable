# Security and private reports

Never file an issue containing passwords, pairing tokens, addresses, serial numbers,
personal photos or raw TV databases. Do not post `.private`, complete command output
or dependency cache files. Delete/redact accidental exposure and revoke affected
credentials rather than assuming editing an issue removes all copies.

Use GitHub's private vulnerability reporting on this repository for a security
issue. Public issues are for sanitized model/build and behavior reports. Do not
upload a proof containing other people's devices or scan networks for TVs.

This tool acts only on an explicitly supplied private LAN IPv4 address. Temporary
root is owner-authorized and short-lived, but still privileged. Apply only to your
own supported TV. Close Developer Mode afterward. The shared viewer, firmware and
global security settings are outside the tool's write scope.
